# ⚖ LawHub

Қазақстан құқықтық актілерінің каталогы, құқық саласына бағыттау және жеке мерзімдер.
Каталог правовых актов Казахстана, подбор области права и личные сроки.

Тілдер / Языки: KZ, RU

## Іске қосу
`index.html` файлын браузерде ашыңыз. Құрастыру қажет емес.

## Apple Watch
`https://maksimgalimahambet-netizen.github.io/Law.watch/?view=watch` сілтемесін өзіңізге Messages немесе Mail арқылы жіберіп, сағаттан ашыңыз.

## GitHub Pages
Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Ескерту
Ақпараттық жоба, жеке заңдық кеңес емес. Ресми мәтінді Әділет жүйесінде тексеріңіз.
